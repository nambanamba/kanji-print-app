# 📝 中学受験 社会 漢字特訓マスター（プリント印刷 & 〇✕記録アプリ）

四谷大塚「予習シリーズ」5年下に準拠した、**中学受験社会の頻出漢字・記述指定重要語に特化した専用プリント作成・学習記録アプリ**です。

---

## 🌟 特長

1. **中学入試の漢字指定・誤字多発ワードを厳選**
   - 平易な漢字（旧石器時代、米、土器など）は排除し、入試で「漢字指定されやすい」「とめ・はね・へん・つくりで失点しやすい」重要語のみを抽出。
2. **A4プリント印刷に完全最適化**
   - **問題用紙**: 手書きしやすい大きめの解答記入枠、タイトル・氏名・得点欄ヘッダー付き。
   - **解答用紙**: 丸つけ用の赤太字解答、漢字の注意ポイント（「竪」と「堅」の違いなど）、解説付き。
3. **〇✕ワンタップ採点 & 苦手優先出題**
   - 印刷したプリントを解いた後、画面上で「〇」「✕」をタップして保存。
   - 間違えた漢字はブラウザ（localStorage）に自動記録され、次回以降のプリントで優先的に出題されます。
4. **スタンドアロン動作**
   - 外部サーバー不要。`index.html` をブラウザ（Chrome / Edge / Safari 等）でダブルクリックするだけで即座に使えます。
   - 元の `kosukequiz-battle` アプリとは完全に独立しており、安全に運用できます。

---

## 🚀 使い方

1. `kanji-print-app` フォルダ内の **`index.html`** をブラウザで開きます。
2. **単元を選択**: 「第1回」「第2回」などのボタンをタップ（複数選択・全選択可能）。
3. **問題数・モードを選択**:
   - 問題数（5問、10問、15問、20問、全問）
   - モード（🔥 苦手優先、🎲 ランダム、📖 番号順）
4. **印刷**:
   - **「🖨️ 問題用紙を印刷 (A4)」** をタップして印刷（またはPDF保存）。
   - **「📄 解答用紙を印刷 (A4)」** で模範解答を印刷。
5. **採点・記録**:
   - 紙で解いた後、画面上の **「〇✕採点・記録」** タブを開き、〇・✕をタップして **「💾 採点結果を保存する」** を押します。

---

## 📁 ファイル構成

- `index.html` - アプリ本体（UI・印刷スタイル・採点・苦手管理ロジック）
- `kanji-data.js` - 厳選漢字データ（第1回・第2回 各20題）
- `README.md` - 本ドキュメント

---

## ➕ 単元データの追加方法

今後、第3回以降のデータや地理・公民の単元を追加する場合は、`kanji-data.js` の `KANJI_DATA` 配列に問題オブジェクトを追加し、`KANJI_UNITS` に単元キーを登録するだけで自動的にアプリに反映されます。
